# APP DE TASACIONES RD
Prototipo web para probar el flujo de expedientes de tasación.

## Render
Build: `pip install -r requirements.txt`
Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`

Esta es una versión de prueba. La fidelidad exacta de la plantilla Word y automatizaciones geográficas avanzadas se validarán con expedientes reales antes de producción.
